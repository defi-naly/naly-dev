# Experiment Log

One variable at a time. Minimum 10 data points before conclusions.

---

## Entry Format

```
### Experiment: [Name]

**Status:** Running / Complete
**Dates:** [start] → [end]

**Hypothesis:** If I [do X], then [Y will happen] because [Z].
**Variable:** [The one thing being changed]
**Control:** [What stays the same]
**Duration:** [Minimum 10 posts or 2 weeks]
**Metric:** [What you're measuring]

**Data:**
| Post | Date | Variable Value | Metric Result |
|------|------|----------------|---------------|
| 1    |      |                |               |

**Result:** [Summary after experiment completes]
**Ruling:** Keep / Kill / Modify
**Notes:**
```
