Manifesto

Cypherpunks write code.

— Eric Hughes, A Cypherpunk's Manifesto, 1993

Self-Custody Changes Everything

When you hold your own keys, no one can freeze your funds, deplatform your savings, or decide what you're allowed to spend on. That's not ideology—it's architecture.

Privacy is Valuable

Every indexed transaction is a data point for someone else's model. Privacy isn't about hiding—it's about not handing over leverage you didn't consent to give.

Open Source Builds Trust

Code you can read is code you can verify. We don't ask for trust—we publish the receipts.

Useful Beats Clever

Elegant abstractions that no one uses are just expensive hobbies. We ship tools that solve real problems people actually have.
